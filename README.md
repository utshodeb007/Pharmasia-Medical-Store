### Project Description
Pharmasia Medical Store is a web-based B2B pharmaceutical ordering and management system. It allows customers to browse medical products, search medicines, check stock availability, add products to the cart, and place orders.

The system also provides an admin dashboard for managing products, monitoring stock, and updating customer orders.
